Skill A folder of markdown the agent can load. The blueprint is a skill that writes other skills.
Orchestrator skills/<project>/SKILL.md, under ~100 lines. Classifies the task and picks a workflow.
Routing matrix The table of contents. Maps task types and commands to one contract each.
Workflow contract workflows/<name>/SKILL.md with eight required sections. One lesson per module or task type.
Review gate Pass or fail checks at the end of a contract. Failures become new invariants.
template.json Machine-readable manifest for CLIs, IDE plugins and CI. Must match the workflows folder.
